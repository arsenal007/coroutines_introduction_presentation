Promise, Awaitable, Handler 🧩

🔄 Coroutine → returns Handler → contains coroutine_handle → points to frame

🎯

TaskHandler

Return type of coroutine
Wraps coroutine_handle

⏳

Awaitable

Object for co_await
await_ready, await_suspend, await_resume

📜

Promise Type

Defines coroutine behavior
initial_suspend, final_suspend, get_return_object...

Return Type (Handler) 🎯

💡 Coroutine returns Handler → caller stores and manages it

📦

Regular C++ Object

  • Constructors, destructors
  • Move/Copy semantics
  • Methods and fields
  • No special "coroutine magic"
👤

Caller Side

  • Caller receives this object
  • Stores and manages it
  • Controls coroutine lifetime
  • Accesses results via Handler

Minimal Coroutine Example 🔬

Return type must have promise_type

nested class

class Handler {
public:
  class promise_type {
    // methods...
  };
};

or via using

class Handler {
public:
  using promise_type = promise;
};

More detailed example: simple.cpp

coroutine — looks like a function

Handler hello() {
  co_return; // ← makes it
}             //   a coroutine

int main() {
  Handler h = hello();
  // h manages lifetime
}

Coroutine Keywords

⏸️
co_await

Suspend until ready
→ returns value

📤
co_yield

Produce value & pause

🏁
co_return

Complete & return

promise_type 📜

Defines coroutine behavior, lives inside the coroutine frame

🚀
initial_suspend()

🏁
final_suspend()

🎁
get_return_object()

Awaitable ⏳

Object passed to co_await, controls how suspension happens

❓
await_ready()

Skip suspension?
returns bool

⏸️
await_suspend()

Called on suspension
receives coroutine_handle

▶️
await_resume()

Called on resume
returns value to co_await
